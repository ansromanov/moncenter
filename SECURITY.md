# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/ansromanov/moncenter/security/advisories/new),
not in a public issue. Include the version, what you did and what you saw.

Fixes go into the latest release; there are no backports while the project is 0.x.
The GitHub Actions are kept current by Dependabot, and the history is
scanned for secrets in CI.
